# KPI Definitions

| KPI | Definition |
|---|---|
| Net Sales | Gross Sales less line-level discounts. |
| Profit | Net Sales less Cost of Goods. |
| Profit Margin % | Profit divided by Net Sales. |
| Orders | Distinct count of OrderID. |
| Customers | Distinct count of CustomerID. |
| Average Order Value | Net Sales divided by distinct Orders. |
| Units Sold | Sum of Quantity. |
| Discount Value | Gross Sales less Net Sales. |
| Return Rate % | Returned sales lines divided by sales lines. |
| Refund Amount | Sum of completed and pending refund amounts. |
| Net Revenue After Returns | Net Sales less Refund Amount. |
| Target Achievement % | Actual Net Sales divided by Target Revenue. |
| Year-on-Year Growth % | Current-period Net Sales versus the same period in the prior year. |
| Repeat Customer % | Customers with more than one distinct order divided by all customers. |
